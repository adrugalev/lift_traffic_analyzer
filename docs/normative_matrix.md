# Матрица нормативного расчёта

## ГОСТ 34758-2021

В приложении реализован расчётный метод для пикового пассажиропотока вверх при
одном нижнем посадочном этаже, равномерном заселении и однородной лифтовой группе.

| Показатель | Зависимость | Ссылка | Реализация |
|---|---|---|---|
| Минимальная номинальная скорость | `Vн = Hmax / tн` | п. 6.5.2, формула (1), таблица 4 | `AnalyticEngine.calculate_normative` |
| Номинальная вместимость | `Pном = round(Q / 75)` | п. 6.5.3 | `AnalyticEngine.calculate_normative` |
| Расчётная загрузка кабины | `Pк = round_half_up(kз × Pном)` до целого пассажира | п. 6.5.3; принятое правило округления по примерам приложения Е | `calculated_capacity` |
| Время входа/выхода пассажира | выбор по ширине двери | п. 6.4, таблица 3 | `AnalyticEngine.calculate_normative` |
| Провозная способность за 5 минут | `P5 = 300 × Pк × Nл / T` | раздел 7, формула (4) | `AnalyticEngine.calculate_normative` |
| Интервал | `tи = T / Nл` | раздел 7, формула (5) | `AnalyticEngine.calculate_normative` |
| Удельная провозная способность | `%P5 = P5 × 100 / A` | раздел 7, формула (6) | `AnalyticEngine.calculate_normative` |
| Время кругового рейса | по формуле RTT стандарта | раздел 7, формула (7) | `AnalyticEngine.calculate_normative` |
| Время движения на этаж | `tэт.н = hэт / Vн` | раздел 7, формула (8) | `AnalyticEngine.calculate_normative` |
| Фактическое межэтажное время | идеальный S-профиль с ограничениями `a`, `b`, `j`; номинальная скорость достигается только при достаточной длине пролёта | п. 3.10; параметр `tэт` формулы (9); зафиксированная кинематическая интерпретация | `jerk_limited_travel_time` |
| Время остановки | по временам дверей, пуска и движения | раздел 7, формула (9) | `AnalyticEngine.calculate_normative` |
| Вероятное число остановок | `S = Nэт × [1 − (1 − 1/Nэт)^Pк]` | раздел 7, формула (10) | `AnalyticEngine.calculate_normative` |
| Этаж реверса | `Nр = Nэт − Σ(i/Nэт)^Pк` | раздел 7, формула (11) | `AnalyticEngine.calculate_normative` |

Критерии провозной способности и интервала берутся из таблицы 1, диапазоны
времени движения на всю высоту — из таблицы 4. Трассировка каждого результата
содержит формулу, подстановку, единицу измерения и пункт стандарта.

Отдельный отчёт «По ГОСТ» повторяет состав раздела 9: общие сведения, сведения
о здании, критерии проектирования, параметры лифтовой установки, расчётные
данные, выводы, ограничения и аудит. Таблица этажей включает поля формы
приложения Б.

## Контроль

- нормативные формулы хранятся в `config/formulas.yaml`;
- критерии — в `config/normative_values.yaml`;
- эталонный пример приложения Д покрыт regression-тестами;
- `eval()` не используется;
- договорный выпуск должен быть проверен по экземпляру стандарта заказчика.
