## Критерии качества

- одинаковый проект и seed дают одинаковый результат симуляции;
- нормативный режим работает только в заявленной области применимости;
- каждая нормативная формула содержит номер пункта, подстановку и единицы;
- эталонный пример ГОСТ покрыт regression-тестами;
- экспортные форматы повторно открываются библиотеками чтения;
- PDF-форма отчёта проверяется постраничным рендерингом.
