# Версионирование приложения

Отображаемая версия имеет формат:

```text
НОМЕР_ДД.ММ.ГГГГ
```

Пример: `2_29.07.2026`.

- Номер увеличивается на единицу после завершённого пакета изменений.
- Промежуточные правки внутри одной задачи не создают отдельную версию.
- Версия считается выпущенной после прохождения проверок и готовности обновления к использованию.
- Дата — дата выпуска этой версии, а не дата запуска приложения.

Номер и дата задаются один раз в `src/__init__.py`. Полная версия автоматически
отображается в настройках и включается в аудит DOCX/PDF-отчётов. Базовая
совместимая с Python-пакетами техническая версия дублируется в `pyproject.toml`.
