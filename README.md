# Расчёт пассажиропотока EPSS

Локальное Streamlit-приложение для расчёта и моделирования пассажиропотока
лифтовых групп.

## Что реализовано

- расчётный метод ГОСТ 34758-2021 для пикового пассажиропотока вверх:
  формула (1), формулы (4)–(11), таблицы 1, 3 и 4;
- проверка области применимости метода;
- трассировка формул, подстановок, единиц и пунктов стандарта;
- отдельный DOCX/PDF-отчёт «По ГОСТ» по составу раздела 9;
- форма этажей с полями приложения Б;
- предварительный инженерный расчёт и сравнение вариантов;
- дискретно-событийная симуляция;
- экспорт DOCX, PDF и XLSX;
- 10 русскоязычных страниц Streamlit.

## Быстрый запуск в Windows PowerShell

Требуется Python 3.11+.

```powershell
cd C:\путь\к\lift_traffic_analyzer
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m streamlit run app.py --server.port 8501
```

После запуска откройте `http://localhost:8501`.

Если страница не открывается:

```powershell
python -m streamlit run app.py --server.address 127.0.0.1 --server.port 8501
```

Проверьте, что терминал остаётся открытым и в нём нет сообщения о занятом порте.

## Работа с приложением

1. Заполните объект и этажи.
2. Проверьте лифты и времена дверей.
3. Задайте сценарий восходящего пика.
4. На странице «Расчёт и отчёт» выполните расчёт по ГОСТ.
5. Скачайте DOCX или PDF под кнопкой нормативного расчёта.

## Методологические ограничения

- метод ГОСТ реализован для восходящего пика, одного нижнего посадочного этажа,
  равномерного заселения и однородной группы;
- ориентировочное время ожидания `I/2` является вспомогательным и не считается нормативным
  критерием ГОСТ;
- симуляция использует упрощённую диспетчеризацию;
- договорный отчёт должен быть проверен по экземпляру стандарта заказчика;
- энергопотребление и стоимость без подтверждённых моделей не рассчитываются.
