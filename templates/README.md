# Шаблоны

Версия приложения хранится централизованно в `src/__init__.py` в формате
`номер_дд.мм.гггг`. DOCX формируется программно в
`src/reports/docx_report.py`, чтобы отчёт всегда соответствовал текущей схеме
данных.

`calculation_report.docx` — визуально проверяемый референс текущей структуры отчёта. Генератор не зависит от бинарного файла и воспроизводит стили программно. При появлении корпоративного образца его можно заменить и адаптировать генератор без копирования дизайна сторонних программ.
